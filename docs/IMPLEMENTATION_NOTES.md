# Implementation Notes - Challenge Tier Economy

## Current Working Loop

The current intended loop is:

1. Player learns from a shrine.
2. Player clears a gate challenge.
3. First clear grants Code Shards.
4. Player may spend Code Shards at the Shop Terminal.
5. Optional side challenges provide extra Code Shards and mastery practice.
6. Boss Bug validates integrated knowledge and reveals that bugs are intentional.

## Economy Rule

Code Shards should never buy direct answers. They can buy support tools only. This keeps the learning intact while still giving the player strategic agency.

Approved purchases:

- Extra Chance
- ARIA hint token
- Retry shield
- Reveal one corrupted line
- Terminal skins
- Lore fragments
- Map pings for side challenges

Avoid:

- Buy the answer
- Auto-complete challenge
- Skip boss bug
- Remove required learning gates

## Side Challenge Rule

Side challenges must be based on concepts already introduced. They should feel like mastery checks, not surprise lessons.

Good formats:

- Output prediction
- Bug hunt
- Repair sprint
- Memory rebuild
- Concept lock

## Narrative Rule

Bugs are intentional and evolve. ARIA stays helpful. The player should feel like the corruption is fighting back, not like ARIA betrayed them.
